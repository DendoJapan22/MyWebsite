# ドラシルデジタル / Drasil Digital

地方の工務店専門のWeb制作サービス「ドラシルデジタル」のコーポレートサイトです。
「ドラシルデジタル」は Drasil(屋号)が運営する最初の事業です。

ブランド構造:

- 屋号(法的な実体): Drasil
- 対外的なサービス名: ドラシルデジタル / Drasil Digital
- ターゲット顧客: 地方の小規模工務店(経営者は40〜70代が中心)

## 開発

開発サーバーの起動:

```bash
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

## よく使うコマンド

```bash
npm run dev          # 開発サーバー(ホットリロード)
npm run build        # 本番ビルド
npm run start        # 本番サーバー
npm run lint         # ESLint
npm run test:e2e     # Playwright E2E
```

## 技術スタック

- Next.js 16(App Router)
- React 19
- Tailwind CSS v4
- Framer Motion
- shadcn/ui + Base UI
- React Hook Form + Zod
