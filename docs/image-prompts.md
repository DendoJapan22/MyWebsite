## 仕上げチェックリスト

- [ ] 出力後、文字や顔が混入していないか目視確認(混入したら再生成)
- [ ] 既存3点と並べて、彩度・暖色感が大きく外れていないか確認
- [ ] Photoshop で 彩度 -10〜-20、暖色 +5 で揃える(必要に応じて)
- [ ] `public/images/_inbox/` に投入 → 同じ webp 変換手順で組み込み
- [ ] 細長帯は 2400×240 程度、それ以外は長辺 1920px が目安

## 変換コマンドの再利用

```bash
node -e "
const sharp = require('sharp');
const path = require('path');
const fs = require('fs');
const inbox = 'public/images/_inbox';
const out = 'public/images';
const mapping = [
  { from: 'YOUR_FILENAME.png', to: 'about-craft-balance.webp', maxW: 1920 },
];
(async () => {
  for (const m of mapping) {
    await sharp(path.join(inbox, m.from))
      .resize({ width: m.maxW, withoutEnlargement: true })
      .webp({ quality: 84 })
      .toFile(path.join(out, m.to));
  }
})();
"
```
